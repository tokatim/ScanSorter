# Сторонние компоненты

Лицензия активации ScanSorter относится к приложению. Используемые сторонние компоненты распространяются на собственных условиях.

| Компонент | Лицензия / сведения |
|---|---|
| Tesseract .NET wrapper 5.2.0, Charles Weld | Apache-2.0; https://github.com/charlesw/tesseract |
| Tesseract OCR и русский словарь tessdata | Apache-2.0; https://github.com/tesseract-ocr/tessdata |
| Leptonica | BSD; см. third-party/Leptonica-BSD.txt |
| PaddleOCR / PP-OCRv5, модель распознавания | Apache-2.0; https://github.com/PaddlePaddle/PaddleOCR |
| RapidOCR, распространение ONNX-моделей | Apache-2.0; https://github.com/RapidAI/RapidOCR |
| Docnet.Core 2.6.0 | MIT; см. third-party/Docnet-MIT.txt |
| PDFium и включённые зависимости | См. third-party/PDFium-LICENSE.txt |
| ONNX Runtime 1.19.2 | MIT и уведомления о зависимостях; см. third-party/ONNXRuntime-* |
| Microsoft .NET 8 | MIT и уведомления о зависимостях; см. third-party/dotnet-* |

Полные тексты и уведомления находятся в папке third-party и входят в ZIP-архив релиза.
